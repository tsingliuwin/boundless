# PPT / 幻灯片构图规范

用户要求 PPT、幻灯片、演示文稿、课件、翻页展示时，按以下规范逐页制作。核心原则：**每页先 add_page 开页，再在该页矩形内排版；页面即边界，任何元素都不得越出页面或落在页面之间的空隙里**。

1. **规划页目**：动笔前先在思考里定页数与每页主题。典型结构：封面页 → 目录/议程页 → 2~6 张内容页（每页一个要点组）→ 总结/致谢页。除非用户指定，总页数 5~8 页。
2. **比例**：用户指定了比例（如 16:9、4:3、9:16 竖屏）时，**每一页**的 add_page 都要传相同的 ratio；未指定默认 16:9。全部页面比例必须一致。
3. **逐页制作**：对每一页，先调用 add_page(title=页标题, ratio=比例)，工具会返回该页的矩形 (x,y) 尺寸 w×h；然后本页的所有元素都画在这个矩形内，四周留 ≥30 边距。**页面之间的空隙（相邻页之间的间隔地带）绝对不放任何元素**。一页画完再开下一页。
4. **页面版式**（以返回的页面矩形为基准，设页左上角为 (px, py)、尺寸 pw×ph）：
   - **横屏页（pw > ph，16:9 / 4:3）**：标题区在页顶部，标题字号 40~48（封面页大标题 64~72），y ≈ py + 40；正文紧随标题下方 30 起，字号 20~26，每页 3~5 个要点，条目间距 ≥ 20。
   - **竖屏页（ph > pw，9:16 / 3:4）**：内容必须**纵向铺满版心**，不能堆在上半部——标题 y ≈ py + 60（字号 44~52）；正文条目从 y ≈ py + 0.20×ph 开始，到 y ≈ py + 0.82×ph 结束，条目纵向均分（间距 = 可用高度 ÷ 条数，通常 ≥ 90）；每个条目内部（小标题 + 说明文字）也要留出呼吸间距。卡片/图示组同样纵向排列或 2×2 铺满中段，不要全部挤在页面上部。
   - **居中规则**：页内水平居中的文字（封面大标题、致谢页大字）用 draw_text 的 anchor="center" 且 x = px + pw/2（页面中线）——**不要自己按字数计算左上角偏移**。
   - **构图铁律（两种比例都适用）**：正文内容的纵向跨度必须 ≥ 页高的 60%；页面底部 10% 区域只放页码（右下角 (px + pw − 60, py + ph − 50)，字号 14~16，中性灰）；不要让下半页整段空白。
5. **文字纪律**：每段正文必须给 wrap_width（≤ 页宽 − 120）；每个文本的宽度估算（字数 × 字号）不得超出页面右边界；标题字号与正文字号层级差 ≥ 1.8×。
6. **配色**：默认白底浅色页面（不要调用 set_canvas_background 设深色底，除非用户明确要求暗色主题）。主色贯穿：选一个主色（如 0x1a5fd7 蓝、0x2f9e44 绿、0x7048e8 紫），标题、描边、序号、强调元素统一用它。**卡片与色块的填充一律用主色的浅色调**（如蓝主色配 0xE7F0FF、绿主色配 0xE6F4EA 的浅底），其上放深色文字；或白底 + 主色描边。**禁止高饱和刺眼填充**（洋红 0xFF00FF、品红、纯红 0xFF0000、荧光色）——大面积刺眼色块是排版事故，与主色冲突会毁掉整份 PPT 的观感。
7. **装饰克制**：封面页可加主色色带/大色块（solid 填充矩形）+ 标题；内容页只用小装饰（序号圆点、主色细线分隔），不要每页堆满插图。
8. **完成自检**：全部页画完后调用一次 list_elements 终检——每页都有标题文字、无文字重叠、无元素落在页面矩形之外。发现问题用 update_element 修正。
