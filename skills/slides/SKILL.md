# PPT / 幻灯片构图规范

核心设计哲学：**这是一块手绘白板，PPT 是一场手绘演示**，不是排版软件输出的 flat design。两件事让每份 PPT 独一无二：一是**手绘质感**（排线、水彩、抖动的线条、随手批注——这是画布的本性，别磨平它）；二是**内容涂鸦**（跟着主题走的简笔画——涂鸦没法套模版，画了火箭就不会像讲了桥梁的那份）。在"自己的设计"之内保持克制与一致（Garr Reynolds：简洁、每秒可懂）；一页只讲一个观点。

## 〇、动笔前：设计简报（强制）

开第一页之前，先用一句话向用户报出设计方向（报完直接开画，不等确认），四要素全部从内容推导：

1. **视觉概念**：这份内容像什么？找一个隐喻贯穿全篇（产品发布→升空的火箭；季度复盘→登山的路标；人文课→摊开的手账）。用户指定的品牌色/风格永远优先于推导。
2. **主色**：推导顺序 = 用户指定色 > 领域联想 > 情绪。硬红线（工具会直接拒收）：纯红/亮橙红（r≥200 且 g、b≤90，如 0xE03131、0xE8590C）、洋红粉紫族、荧光高饱和。**深色或中饱和 hue 永远安全**——藏蓝、墨绿、酒红、青碧、琥珀、紫罗兰……全篇只用这一个主色。
3. **叙事架构**：整本 PPT 用哪副骨架？章节推进体（传统封面→目录→章节）/ 旅程地图体（一条大路线，内容是沿途站点）/ 问题-解方体（左问右答贯穿）/ 时间长河体（沿一条时间线展开）/ 分镜故事体（连续画面+旁白）。**不同架构连"有没有目录页"都不同**——先定它，页面骨架自然不会千篇一律。
4. **涂鸦母题**：列出全篇复用的 2~3 个简笔画意象（火箭、台阶、灯泡、桥梁、天平、对话框、小人……），它们从视觉概念长出来。

简报就是这份 PPT 的身份证——之后每一页都要能追溯回它。

## 一、手绘质感铁律（全篇强制，这是与一切"平面设计规范"的分界线）

1. **roughness 全篇 1~1.5**（画布默认 1.0，**别传 0**；"锐利/科技感"也不许归零——抖动的笔迹是本画的身份）。
2. **填充质感**：大色块用 hachure / dense / watercolor（排线是默认，理想状态是"少指定"）；**solid 只允许小面积**（序号方块、强调标签，合计 ≤ 页面 10%）。禁止大面积 solid 平涂色块。
3. **线条要像手画的**：下划线、圈重点、手绘框用多点 polyline 微微起伏（同一笔 3~5 个点，别用完美水平线）；圈重点 = 无填充椭圆 + rough 描边；指引、关联、推导一律用 arrow。
4. **文字仍然排正**：字号阶梯、对齐、wrap 照常执行——手绘感来自形与线，不来自把文字画歪。

## 二、设计系统（全篇不变量，动笔即锁定）

1. **60-30-10 配色**：主色 60%（排线/水彩色块、标题、涂鸦、序号）+ 中性 30%（白/浅底、灰说明 0x868e96）+ 强调 10%（主色加深或深灰 0x1e1e1e）。中性色不引入第二个 hue。
2. **字号阶梯**（相邻层级差 ≥ 1.5×）：封面大字 64~88 ｜ 页标题 40~52 ｜ 小节/卡片标题 24~30 ｜ 正文 20~24 ｜ 辅助（说明、来源、页眉）14~16 ｜ 数据大数字 64~88。
3. **版心网格**：所有页面统一边距——左右 ≥ 60、上 ≥ 50、底部 10% 只放页码；每页标题永远在同一位置（左上或居中，二选一坚持全篇）；同组卡片等宽等高、间距一致（24~40）。
4. **接近性原则**：组内元素紧挨（间距 8~16），组与组之间拉开（间距 ≥ 40）——用间距表达结构。

## 三、信息密度（少即是多）

1. **一页一个核心观点**；标题写结论而不是话题（「主动回忆：测过才记得住」✓，「主动回忆介绍」✗）。
2. 要点 **3~5 个**，每要点 ≤ 2 行（正文 ≤ 24 字）；整页正文总字数 ≤ 120 字。放不下就拆页，不缩小字号硬塞。
3. **能画不写**：数据用「大数字 + 手绘柱/线 + 短标签」；流程用 arrow 串涂鸦节点；对比用分栏。不写成段落的文字。

## 四、内容涂鸦（每页的魂，反模版化的主引擎）

1. **每页至少 1 个从内容长出来的涂鸦**，2~6 个形状组合的小画：火箭 = 三角+矩形+两笔尾焰线；灯泡 = 圆+小矩形底+几条短光芒线；台阶/增长 = 阶梯折线+向上箭头；桥梁 = 弧线+桥墩竖线；天平 = 横线+中柱+两个吊盘；对话框 = 椭圆+小三角尾；小人 = 圆头+躯干+四肢线（姿势要有含义，参考 comic 技能的肢体语言）。
2. **封面必须有一幅主涂鸦场景**（占版面 ≥ 15%），结尾页与它呼应——首尾同一意象，中间各页的涂鸦是它的变奏。
3. 涂鸦只用主色 + 中性灰，至多一处强调色；**禁止与内容无关的装饰堆砌**（画了不说明问题的小花小草是减分项）。

## 五、版式启发（不是菜单——换了架构或换一组涂鸦，画法自然不同）

先守住不变量与手绘铁律；居中一律 anchor="center" 且 x = 页面中线。

1. **封面**：主涂鸦场景 + 大字标题，构图随架构走——出血排线底、大图占半、不对称留白、或涂鸦从标题下生长出来。元素 ≤ 8，底部信息 16~18 灰。
2. **目录/议程**（章节推进体才需要；旅程体改画"路线总览"）：4~6 条，序号 + 手绘小图标（每条的涂鸦母题变奏）。
3. **要点页**：3~5 条——圆点/手绘序号 + 加粗短句 + 一行灰说明；某一条被 arrow 指向涂鸦特写 = 本页重心。
4. **卡片页**：等宽网格或主次卡；卡片 = 排线填充 + rough 描边，卡内一小片涂鸦 > 三行文字。
5. **数据页**：手绘柱形（最后一根主色 dense，其余灰排线）+ 大数字 64~88 + 涂鸦标注（上升箭头、惊叹线、圈重点）。
6. **对比页**：左右两栏，中缝一条起伏线；两栏标题主色 vs 0x868e96；两栏各配一个对立涂鸦（天平两端）。
7. **流程/时间轴**：arrow 串联节点，节点 = 涂鸦小图标 + 阶段名；里程碑节点画大一圈。
8. **引言页**：整页留白 + 一句大字（36~48）+ 手绘引号 + 出处小字灰。全篇 ≤ 1 页。
9. **章节过渡**：超大序号 80~100 + 章节名 + 该章涂鸦母题的一个局部特写。
10. **结尾页**：主涂鸦意象收尾 + 大字「谢谢观看」（anchor="center"）+ 一行信息 16~18 灰。元素 ≤ 6。

## 六、签名元素（每份 PPT 一个记忆点）

从视觉概念推导一个小记号，每页出现一次、全篇样式与位置绝不更改（这是唯一允许的重复）：标题旁的手绘小图标 ／ 页角一枚歪斜的序号章 ／ 标题下两笔起伏短横线。要"像手盖上去的"，不要几何色带。

## 七、动效（add_page 的 effect 参数）

每页可指定自己的过渡动效，放映翻到该页时、以及放映从该页开始（开场）时生效：

- **slide**（默认）：相机从当前取景横扫滑入该页——空间连续感最强，适合绝大多数演示；
- **fade**：经黑淡入淡出（淡出约 140ms + 黑场约 80ms + 淡入约 260ms）——适合章节切换、情绪转折页；
- **none**：硬切——适合快节奏的连续要点页。

没提就按叙事架构选，全篇一致；封面（第一页）的 effect 同时是整场放映的开场特效。

## 八、流程纪律

1. **严格逐页制作**：开第 N 页 → **立即画完第 N 页的全部内容** → 再开第 N+1 页。**绝不要先把所有页面一次开完再回头逐页填内容**——观看者会长时间面对一排空页面。
2. **比例**：用户指定了比例时，每一页的 add_page 都传相同 ratio；未指定默认 16:9。全篇比例必须一致。
3. **页面即边界**：本页所有元素画在 add_page 返回的矩形内，四周留 ≥ 30 边距；页面之间的空隙绝对不放任何元素。
4. **竖屏页（ph > pw）**：正文条目从 y ≈ py + 0.20×ph 铺到 y ≈ py + 0.82×ph 纵向均分（间距通常 ≥ 90）；封面也保持纵向节奏。
5. **居中**：页内水平居中的文字一律用 draw_text 的 anchor="center" 且 x = 页面中线（px + pw/2），不要按字数心算左上角偏移。
6. **正文换行**：每段正文必须给 wrap_width（≤ 页宽 − 120）。
7. **对比铁律**：主色深色色块上的文字必须用白色或极浅色（深底浅字）；浅色卡片/白底上用深色文字——文字永远与它落的底色强对比。
8. **完成自检**：全部页画完后调用一次 list_elements 终检——每页有标题、无重叠、无越页、层级差达标、全篇主色一致、签名元素每页在场、roughness 无一处为 0；发现问题用 update_element 修正。
9. **反模板自检**：终检时三问——(a) 这份 PPT 除了文字和矩形还有别的吗？Line/Arrow/涂鸦加起来不足元素总数 15% 就是退化成了 flat 排版，退回重画；(b) 封面和至少两页能否追溯到设计简报的涂鸦母题？(c) 换一个主题，这套骨架是否就不成立了？三问有任一不过，重画差异最大的两页。
