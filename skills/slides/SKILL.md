# PPT / 幻灯片构图规范

核心设计哲学（Garr Reynolds《Presentation Zen》）：**克制、简洁、每秒可懂**。一页只讲一个观点，视觉元素 3 秒内能看完；文字堆砌的幻灯片是最严重的设计事故。

## 一、设计系统（动笔前先定，全篇绝不更改）

1. **配色 60-30-10**：选一个主色占 60%（色块、标题、序号）+ 中性色 30%（白底、灰说明文字 0x868e96）+ 强调色 10%（深色文字 0x1e1e1e 或主色加深）。推荐整套色板任选其一：蓝（主 0x1a5fd7 / 浅底 0xE7F0FF）、绿（主 0x2f9e44 / 浅底 0xE6F4EA）、紫（主 0x7048e8 / 浅底 0xEDE6FD）、暖橙（主 0xE8590C / 浅底 0xFFE8D9）。**高饱和刺眼填充（洋红/纯红/荧光）会被系统直接拒收**。全篇只此一套色板。
2. **字号阶梯**（相邻层级差 ≥ 1.5×）：封面大字 64~88 ｜ 页标题 40~52 ｜ 卡片/小节标题 24~30 ｜ 正文 20~24 ｜ 辅助（说明、来源、页眉）14~16 ｜ 数据大数字 64~88。
3. **版心网格**：所有页面统一边距——左右 ≥ 60、上 ≥ 50、底部 10% 只放页码；每页的标题永远在同一个位置（左上或居中，二选一坚持全篇）；同组卡片必须等宽等高、等间距（24~40）。
4. **接近性原则**：组内元素紧挨（间距 8~16），组与组之间拉开（间距 ≥ 40）——用间距表达结构，不画框也能分区。
5. **装饰克制**：顶部一条主色细色带（高 8~12）可当全篇品牌线；除此之外的装饰只允许：序号圆点/方块、细分隔线、主色下划线。不要每页堆插图。

## 二、信息密度（少即是多）

1. **一页一个核心观点**；标题写结论而不是话题（「主动回忆：测过才记得住」✓，「主动回忆介绍」✗）。
2. 要点 **3~5 个**，每要点 ≤ 2 行（正文 ≤ 24 字）；整页正文总字数 ≤ 120 字。放不下就拆页，不缩小字号硬塞。
3. **能画不写**：数据用「大数字 + 短标签」（数字 64~88 号主色，标签 14~16 灰）；流程用带序号的步骤；对比用左右两栏。不写成段落的文字。

## 三、页面类型版式库（每页先判断类型，再按版式落笔）

1. **封面**：二选一——(a) 上部 1/3 主色 solid 大色块 + 白色大标题（anchor="center"）+ 色块下方副标题；(b) 全白 + 超大标题（anchor="center"，页面中线）+ 主色细下划线 + 副标题。封面元素 ≤ 6 个（大标题/副标题/一行日期或主讲人），底部信息用 16~18 灰。
2. **目录**：标题 + 4~6 个条目纵向均分（占页高 20%~82%）。每条 = 主色序号方块（24×24，**内部必须写白色数字** 01/02/03…，字号 12~14）+ 条目名 24 + 一行说明 16 灰。
3. **章节过渡页**（页数多时用）：超大序号 80~100 主色 + 章节名 40，其余全部留白。
4. **要点页**：标题 + 3~5 条目纵向均分。每条 = 主色序号圆点/方块 + 加粗短句 22~24 + 一行说明 16~18 灰色。
5. **卡片页**：2×2 或 1×3 卡片**从 y ≈ py + 0.20×ph 铺到 y ≈ py + 0.82×ph**（卡片区总高 ≥ 0.55×ph，不要挤在上中段留出大片底部空白）。每卡 = 浅底色 solid 矩形（主色浅调）+ 主色描边 1~2 + 卡片标题 24~26（主色或深色）+ 2~3 行说明 18。卡片间距始终一致。
6. **数据页**：「大数字」阵列（2×2 或 1×3）——**所有数据数字统一 64~88 号主色**（如「1200万+」「98%」「40%」），标签 14~16 灰且与数字间距 ≥ 16；趋势用 3~4 根简单柱形（矩形，最后一根主色、其余中性浅灰 0xDEE2E6），不用坐标轴；底部一行来源/口径 14 灰。
7. **对比页**：左右两栏等宽卡片，各自栏标题 26（用两个不同深浅：主色 vs 0x868e96），每栏 3 条以内短要点。
8. **时间轴页**：一条水平主轴线（线 2~3）+ 3~5 个节点（主色圆点 16~20）+ 节点上下交替放「阶段名 20 + 一行说明 16」。
9. **结尾页**：与封面呼应（同款色块或留白），大字「谢谢观看」（anchor="center"）+ 一行联系信息 16~18 灰。元素 ≤ 4 个。

## 四、流程纪律

1. **严格逐页制作**：开第 N 页 → **立即画完第 N 页的全部内容** → 再开第 N+1 页。**绝不要先把所有页面一次开完再回头逐页填内容**——观看者会长时间面对一排空页面。
2. **比例**：用户指定了比例时，每一页的 add_page 都传相同 ratio；未指定默认 16:9。全篇比例必须一致。
3. **页面即边界**：本页所有元素画在 add_page 返回的矩形内，四周留 ≥ 30 边距；页面之间的空隙绝对不放任何元素。
4. **竖屏页（ph > pw）**：正文条目从 y ≈ py + 0.20×ph 铺到 y ≈ py + 0.82×ph 纵向均分（间距通常 ≥ 90）；封面也保持纵向节奏。
5. **居中**：页内水平居中的文字一律用 draw_text 的 anchor="center" 且 x = 页面中线（px + pw/2），不要按字数心算左上角偏移。
6. **正文换行**：每段正文必须给 wrap_width（≤ 页宽 − 120）。
7. **对比铁律**：主色深色色块上的文字必须用白色或极浅色（深底浅字）；浅色卡片/白底上用深色文字——文字永远与它落的底色强对比。
8. **完成自检**：全部页画完后调用一次 list_elements 终检——每页有标题、无重叠、无越页、层级差达标、全篇色板一致；发现问题用 update_element 修正。
