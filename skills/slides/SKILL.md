# PPT / 幻灯片构图规范

核心设计哲学：**每份 PPT 独一无二**。设计从这份内容里长出来——隐喻、主色、气质都由主题推导，而不是套一个万能骨架换配色。在"自己的设计"之内保持极致克制与一致（Garr Reynolds《Presentation Zen》：简洁、每秒可懂）；克制是基于内容的取舍，不是固定剧本。一页只讲一个观点，视觉元素 3 秒内能看完。

## 〇、动笔前：设计简报（强制）

开第一页之前，先用一句话向用户报出设计方向（报完直接开画，不等确认），三要素全部从内容推导：

1. **视觉概念**：这份内容像什么？找一个隐喻贯穿全篇（产品发布→聚光灯舞台；季度复盘→仪表盘；人文课→编辑部版面）。用户指定的品牌色/风格永远优先于推导。
2. **主色**：推导顺序 = 用户指定色 > 领域联想 > 情绪。硬红线（工具会直接拒收并打断节奏）：纯红/亮橙红（r≥200 且 g、b≤90，如 0xE03131、0xE8590C）、洋红粉紫族、荧光高饱和。**选深色或中饱和 hue 永远安全**——藏蓝、墨绿、酒红、青碧、琥珀、紫罗兰……hue 随内容定，全篇只用这一个主色。
3. **气质三词**：如「编辑部 / 大留白 / 锐利」或「温暖 / 手绘 / 紧凑」，并落地为全篇统一的风格旋钮：锐利→roughness 0、直线直角；手绘→roughness 1~1.5；温暖→watercolor / gradient 色块；编辑部→超大字与大片留白。

简报就是这份 PPT 的身份证——之后每一页都要能追溯回它。

## 一、设计系统（全篇不变量，动笔即锁定）

1. **60-30-10 配色**：主色 60%（色块、标题、序号）+ 中性 30%（白/浅底、灰说明 0x868e96）+ 强调 10%（主色加深或深灰 0x1e1e1e）。中性色不引入第二个 hue。
2. **字号阶梯**（相邻层级差 ≥ 1.5×）：封面大字 64~88 ｜ 页标题 40~52 ｜ 小节/卡片标题 24~30 ｜ 正文 20~24 ｜ 辅助（说明、来源、页眉）14~16 ｜ 数据大数字 64~88。
3. **版心网格**：所有页面统一边距——左右 ≥ 60、上 ≥ 50、底部 10% 只放页码；每页标题永远在同一位置（左上或居中，二选一坚持全篇）；同组卡片等宽等高、间距一致（24~40）。
4. **接近性原则**：组内元素紧挨（间距 8~16），组与组之间拉开（间距 ≥ 40）——用间距表达结构，不画框也能分区。

## 二、信息密度（少即是多）

1. **一页一个核心观点**；标题写结论而不是话题（「主动回忆：测过才记得住」✓，「主动回忆介绍」✗）。
2. 要点 **3~5 个**，每要点 ≤ 2 行（正文 ≤ 24 字）；整页正文总字数 ≤ 120 字。放不下就拆页，不缩小字号硬塞。
3. **能画不写**：数据用「大数字 + 短标签」（数字 64~88 号主色，标签 14~16 灰）；流程用带序号的步骤；对比用分栏。不写成段落的文字。

## 三、版式词汇表（按内容自由组合，禁止每页同构）

先守住不变量（边距、对比、密度、居中一律 anchor="center" 且 x=页面中线）；在此之上按内容挑画法，**同一类内容在一篇里鼓励换画法**。

1. **封面**：任选其一——(a) 整版主色出血 + 白色大字（anchor="center"）；(b) 白底超大标题 + 主色签名元素；(c) 不对称分割（1/3 深色竖块 + 大字偏右）；(d) 大图主导（AddImage 主题图占 ~60% 版面 + 角落标题）。元素 ≤ 6，底部信息 16~18 灰。
2. **目录/议程**：4~6 条——(a) 序号方块（内写白字 01/02…）+ 条目纵向均分；(b) 横向柱块等分；(c) 超大幽灵序号（opacity ≤ 0.15）垫底 + 右侧条目。
3. **要点页**：3~5 条——(a) 圆点/方块序号 + 加粗短句 + 一行灰说明，纵向均分；(b) 阶梯错位（逐条右移一档）；(c) 一条竖线贯穿 + 节点挂要点。
4. **卡片页**：等宽网格（2×2 / 1×3）或主次卡（1 大 + 2 小）。卡片区从 y ≈ 0.20×ph 铺到 0.82×ph，总高 ≥ 0.55×ph，不要挤在中上段留出大片底部空白。
5. **数据页**：大数字阵列 / 简柱形（矩形，最后一根主色、其余 0xDEE2E6，不用坐标轴）/ 单根粗横条比例尺。数字 64~88 主色，标签 14~16 灰且与数字间距 ≥ 16；底部一行来源/口径 14 灰。
6. **对比页**：左右两栏等宽卡片 / 上下分层 / 中缝一条细分隔线。两栏标题用两种深浅（主色 vs 0x868e96），每栏 ≤ 3 条短要点。
7. **流程/时间轴**：箭头（arrow）串联步骤 / 水平主轴线 + 节点上下交替 / 纵向阶梯下降。节点 3~5 个。
8. **引言页**：整页留白 + 一句大字（36~48）+ 出处小字灰。全篇最多 1 页。
9. **章节过渡页**：超大序号 80~100 主色 + 章节名 40，其余全部留白；可用 gradient 色块压底增加深度。
10. **结尾页**：与封面呼应（同款色块或同款留白），大字「谢谢观看」（anchor="center"）+ 一行联系信息 16~18 灰。元素 ≤ 4。

装饰词汇：序号圆点/方块（ellipse/rect）、细分隔线、主色下划线、低透明大字水印、gradient/watercolor 色块。禁止：每页堆插图、无意义高饱和填充（撞闸被拒收会打断逐页节奏）。

## 四、签名元素（每份 PPT 一个记忆点）

从视觉概念推导一个小符号或构图习惯，每页出现一次、全篇样式与位置绝不更改（这是唯一允许的重复）：左缘细竖轨 + 当前章节号 ／ 标题下主色短横线 ／ 右下角幽灵序号 ／ 圆角标签页眉……它让 deck 看起来是「设计过的」，而不是「填进去的」。

## 五、动效（add_page 的 effect 参数）

每页可指定自己的过渡动效，放映翻到该页时、以及放映从该页开始（开场）时生效：

- **slide**（默认）：相机从当前取景横扫滑入该页——空间连续感最强，适合绝大多数演示；
- **fade**：经黑淡入淡出（淡出约 140ms + 黑场约 80ms + 淡入约 260ms）——适合章节切换、情绪转折页；
- **none**：硬切——适合快节奏的连续要点页。

用户说「要淡入效果」「渐变切换」用 fade；说「直接切换/不要动画」用 none；没提就按设计简报的气质选，整套动效风格全篇一致。封面（第一页）的 effect 同时是整场放映的开场特效。

## 六、流程纪律

1. **严格逐页制作**：开第 N 页 → **立即画完第 N 页的全部内容** → 再开第 N+1 页。**绝不要先把所有页面一次开完再回头逐页填内容**——观看者会长时间面对一排空页面。
2. **比例**：用户指定了比例时，每一页的 add_page 都传相同 ratio；未指定默认 16:9。全篇比例必须一致。
3. **页面即边界**：本页所有元素画在 add_page 返回的矩形内，四周留 ≥ 30 边距；页面之间的空隙绝对不放任何元素。
4. **竖屏页（ph > pw）**：正文条目从 y ≈ py + 0.20×ph 铺到 y ≈ py + 0.82×ph 纵向均分（间距通常 ≥ 90）；封面也保持纵向节奏。
5. **居中**：页内水平居中的文字一律用 draw_text 的 anchor="center" 且 x = 页面中线（px + pw/2），不要按字数心算左上角偏移。
6. **正文换行**：每段正文必须给 wrap_width（≤ 页宽 − 120）。
7. **对比铁律**：主色深色色块上的文字必须用白色或极浅色（深底浅字）；浅色卡片/白底上用深色文字——文字永远与它落的底色强对比。
8. **完成自检**：全部页画完后调用一次 list_elements 终检——每页有标题、无重叠、无越页、层级差达标、全篇主色一致、签名元素每页在场；发现问题用 update_element 修正。
9. **反模板自检**：终检时多问一句——封面和至少两页的画法能否追溯到设计简报？如果这套骨架原封不动能套到任何主题上，就重画差异最大的两页，直到这份 PPT 只属于这个主题。
