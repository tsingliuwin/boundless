# 漫画 / 分镜连环画构图规范

用户要求漫画、四格漫画、连环画、条漫、分镜时，按以下流程绘制。两条核心原则：

1. **一致性靠模板套件**：一个主角不是一个模板，而是一组「名字-姿势」模板——跨格、跨会话都从同一套件盖章，绝不重画。
2. **生动靠变化**：姿势、角度（rotation）、表情部件、气泡形状每格都要变。**最忌讳的是每格角色都笔直站着、同一表情、只有台词在换**——那是死板的事故，老夫子式的夸张动势才是漫画的灵魂。

主角可以是人、动物（猫/狗/兔子），也可以是设计形象（机器人、食物成精、物件拟人）——一致性要求完全相同：同一套形状与配色模板。

## 一、开工前：查库

1. 第一步调用 list_templates()：库里已有本次要用的角色（按「名字-」前缀找姿势套件）和场景时直接复用，没有的才新画。

## 二、剧本先行（在思考里完成，不落笔）

1. 把用户的故事拆成 3~6 格，每格定五件事：**场景**、**出场角色**、**姿势/动作**（选哪个姿势模板 + rotation 倾斜角）、**表情**（叠加哪些部件）、**台词或旁白**（用什么气泡形状）。
2. **相邻两格的姿态/表情组合不许完全相同**；每个主角在成片中至少出现两种不同姿态。
3. 台词每条 ≤ 18 字，一气泡一至两行；每格对话 ≤ 2 条。
4. 阅读顺序固定：从左到右、从上到下。格与格之间要有因果或时间推进。**最后一格必须收尾，且落在一个具体元素上**：定格表情（夸张眉毛/嘴 + 速度线）、一记独白或旁白、或格底一行「未完待续」小字——禁止只靠一句普通对话平淡收场。

## 三、角色套件与场景入模板库（首次创作时）

1. 在页面外暂存区（y ∈ [1100, 1500]，x 依次 60、400、740…横向排开）给每个主角画**姿势套件**（至少 2 个，建议 3 个）：
   - `名字-站`：标准立姿，高 260~300、宽 140~200，元素 6~14 个——这是其余姿势的基准；
   - `名字-跑`：双腿前后跨开、双臂一前一后、身体前倾的倾斜姿态（画的时候就把四肢摆开，盖章时再叠 rotation）；
   - `名字-坐`：下身收拢、大腿水平的坐姿（配沙发/椅子用）；
   - 剧情特需（可选）：`名字-瘫`、`名字-踢`、`名字-倒` 等。
2. **配色铁律**：同一角色的所有姿势模板用同一套颜色（把「发色/肤色/衣服主色」写进思考，全篇不改）。**辨识三件套**：轮廓剪影（矮胖/瘦高）、主色、标志特征（发型/耳朵/角/天线/胡子）——三个维度至少两个要和别的角色拉开。
3. 每个姿势画完立即 save_template(name=「名字-姿势」, kind="character", ids=[...], delete_source=true)。动物/拟物主角同理（如「橘猫-站」「橘猫-跑」）。
4. 反复出现的场景（教室、公园、客厅）画一份简景（地面线、标志物 3~6 个元素）存 kind="scene" 的模板。

## 四、页面与分格

1. 分格框用 draw_rectangle（fill 白色 solid、stroke 0x1e1e1e、stroke_width 2、roughness 1）。画布 (40,40)-(1560,960) 内：
   - 四格 2×2：格 700×420，列 x = 60 与 840，行 y = 50 与 550（格间距 ≥ 80）；
   - 六格 2×3：格 480×280，列 x = 60 / 560 / 1060，行 y = 50 / 360 / 670；
   - 条横排（条漫）：一行 3~4 格，格 380~480 宽、300~360 高。
2. 格号 ①②③…写在格框左上角外侧（小字号）。

## 五、逐格绘制（一格画完再画下一格）

1. **每格必须落地**：每个格子要么 stamp 场景模板，要么先画一条横贯格底的地面线（y ≈ 格底 − 30，stroke 0x1e1e1e）——角色盖章后**脚底要贴在地面线上**，禁止悬空。
2. **场景**：有场景模板就 stamp_template 盖进格里（scale ≈ 格宽/模板宽，且 ≤ 1.2）。**盖章角色前先看场景标志物（窗/门/家具）的位置，角色 x 要避开**，防止"窗穿头"。
3. **道具要画结构，不画字牌**：电脑/屏幕 = 深色矩形 + 2~3 条彩色短代码线；报错弹窗 = 白底矩形 + 红叉或叹号 + 一行小字；桌子 = 桌面板 + 桌腿。**禁止用只写了名字的空白方块冒充实物**；文字只能作辅助小标注。
4. **角色**：stamp_template(name=「名字-姿势」, x, y, scale≈1, flip_x=朝向, rotation=动势角)——
   - 对话双方**相对而立**（左边的 flip_x=false 面朝右，右边的 flip_x=true 面朝左）；
   - 同一角色在同一格里只出现一次；
   - **rotation 是动势的灵魂**（矩形/椭圆会转成多边形实现，文字不转）：奔跑格 12~20、惊吓/后仰格 -8~-15、得意昂首 -5~-10、摔倒/翻滚 30~45；站姿格保持 0。
5. **缺姿势，现场补建**（画到一半发现套件里没有需要的动作时）：立即在暂存区空位（y ∈ [1100, 1500]）按该角色**同一套配色和辨识特征**画出新姿势（四肢关节摆开，6~14 个元素）→ `save_template(name="名字-新姿势", kind="character", ids=[...], delete_source=true)` 入库 → 再按普通姿势盖章进格子。**禁止拿站姿硬凑动作**（update_element 掰不了关节，站姿挪不成就算），**禁止为画动作整只手绘放弃模板**（那是一致性事故）。同名 save_template 会覆盖旧模板——某个姿势想画得更好，直接同名重存即可升级。
6. **动势配效果线**（画在角色旁，2~4 笔）：
   - 跑：身后 3 条短斜速度线 + 脚后 1~2 条小弧线（尘土）；
   - 惊：头顶 3 根竖发短线 + 汗滴 + 惊叫气泡；
   - 怒：红色十字怒符（「井」形折线）在太阳穴旁；
   - 摔倒/撞击：头顶 2~3 颗黄色小星星（polygon 五角星或十字星）；
   - 开心：小爱心 polygon 或音符（draw_text "♪"）。
7. **大小一致**：同一角色在相邻格中的高度差 ≤ 25%（远景 scale 0.6~0.7，特写 scale 1.5 只盖头部区）。
8. **坐姿**（沙发/椅子/床）：用 `名字-坐` 模板盖在座位后方，**最后画座位前沿矩形**（solid 填充、同色系）盖住大腿，形成"坐进里面"的层次。没有坐姿模板时：盖站姿上移 + 座位前沿盖大腿。禁止站在沙发靠背后方冒充坐姿。
9. **台词**：draw_speech_bubble(x, y, w, h, text, shape=形状, tail=方向)——气泡在格内**上方空白处**，尾巴指向说话者嘴部方向。形状选择：
   - `speech`：普通对话（默认）；
   - `burst`：**惊叫、怒吼、巨响**（"啊——！"、"轰！"）——淡黄爆炸星形框；
   - `thought`：**内心独白、犹豫、盘算**（"要不……算了？"）——思考云圆点尾迹。
   旁白用 draw_rectangle（浅黄 0xFFF9DB solid 底）+ draw_text 放格子顶部。
10. **表情部件库**（在盖出的角色脸上**叠加**小元素，禁止删角色重画）：
   - 眉毛：八字（愁，两条内高外低短线）/ 倒八字（怒，内低外高）/ 一字（平静可省）；
   - 嘴：大 O 椭圆（惊叫）/ 波浪线（委屈）/ 上弯弧（笑）/ 下弯弧（不开心）；
   - 汗滴：小蓝椭圆 fill=0x74C0FC（禁止紫色）挂太阳穴；泪滴同形 0x74C0FC 挂眼下；
   - 其余部件见第 5 条动势配线。
11. **冲突检查**：气泡之间、气泡与角色之间不重叠；气泡完全在自己那格边框内（四周留 ≥ 12）。工具结果里出现 **⚠️ 碰撞提示**时逐条判断：有意遮挡（桌挡腿、坐进沙发）忽略；无意碰撞（窗穿头、道具压脸、同人叠同人）必须 update_element 挪开再画下一格。

## 六、反死板铁律

1. **连续两格禁止相同的「姿势模板 + rotation + 表情组合」**——哪怕台词不同也不行，必须至少换一样。
2. 静态笔直站姿只允许出现在第一格（介绍性画面）和最后一格（定格收尾），中间格必须有动势（姿势变化或 rotation ≠ 0 或速度线）。
3. 惊叫/巨响不用 burst、内心戏不用 thought，算规范违规。
4. 效果线不是装饰：有动作（跑/摔/砸/转）就必须配速度线或星星，没动作不要乱加。

## 七、完成后自检

全部画完后调用一次 list_elements（画的过程中不要反复调）核对：
1. 每个角色在各格中的配色是否与模板套件一致（盖章保证一致，手滑重画了要删掉改成盖章）；
2. 元素是否出格、气泡是否压住角色、文字是否溢出；
3. 每一格的角色脚底是否落地（地面线或座位），有无悬空；
4. **反死板核对**：相邻格的姿势/角度/表情是否都不同？惊叫用了 burst 吗？内心戏用了 thought 吗？
5. 最后一格是否落在了具体收尾元素上。
发现问题用 update_element 修正后再结束。

## 八、禁止行为

- 禁止跳过模板直接在多格里反复手画同一个角色（那是一致性事故）。
- 禁止给同一角色在不同格里换衣服颜色、换标志特征。
- 禁止连续两格角色姿势、角度、表情完全相同（死板事故）。
- 禁止角色悬空：格内既没有地面线/座位、角色脚下也没有支撑。
- 禁止把站立模板原样摆在沙发/椅子靠背后方冒充坐姿。
- 禁止拿站姿模板硬凑没画过的动作、或为动作整只手绘——缺姿势就现场补建模板（见五.5）。
- 禁止把气泡画出格框、盖住关键角色；惊叫不用 burst、内心戏不用 thought。
- 禁止用只写了名字的空白方块冒充实物道具。
- 禁止一格里塞超过 3 个角色或 3 条对话。
- 禁止没有剧本就直接开画（先在思考里把分格表列全，含每格的姿势/角度/表情）。
