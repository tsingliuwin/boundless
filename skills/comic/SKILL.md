# 漫画 / 分镜连环画构图规范

用户要求漫画、四格漫画、连环画、条漫、分镜时，按以下流程绘制。核心原则：**人物和场景一致性靠模板保证——每个角色只画一次、存成模板，之后每一格都用 stamp_template 盖章复用，绝不重画**。

## 一、开工前：查库

1. 第一步调用 list_templates()：库里已有本次故事要用的角色/场景时直接复用（跳过第二步），没有的才新画。

## 二、剧本先行（在思考里完成，不落笔）

1. 把用户的故事拆成 3~6 格，每格定四件事：**场景**（哪里的背景）、**出场角色**（谁在画面里、朝向如何）、**动作/表情**、**台词或旁白**。
2. 台词每条 ≤ 18 字，一气泡一至两行；每格对话 ≤ 2 条。
3. 阅读顺序固定：从左到右、从上到下。格与格之间要有因果或时间推进，最后一格收尾（包袱/结论/留白）。

## 三、角色与场景入模板库（首次创作时）

1. 在页面外的暂存区（y ∈ [1100, 1500]，x 依次 60、400、740…横向排开）画**角色标准像**：立姿全身，高 260~300、宽 140~200，头:身 ≈ 1:3（Q版）或 1:5；**每个角色一套固定配色**（发色、肤色、衣服主色写进思考，全篇不改）。用 draw_ellipse/draw_rectangle/draw_polygon/draw_text 组合，元素 6~14 个为宜。
2. 画完立即 save_template(name=角色名, kind="character", ids=[该角色全部元素id], delete_source=true)——原画从画布收进模板库，页面保持干净。**一个角色一次 save_template，画完一个存一个**。
3. 反复出现的场景（如教室、公园）同样画一份背景简景（地面线、标志物 3~6 个元素）存 kind="scene" 的模板。
4. 角色差异要拉开：至少在发型、衣服主色、身高比例三方面互相不同，读者一眼能认出谁是谁。

## 四、页面与分格

1. 分格框用 draw_rectangle（fill 白色 solid、stroke 0x1e1e1e、stroke_width 2、roughness 1）。画布 (40,40)-(1560,960) 内：
   - 四格 2×2：格 700×420，列 x = 60 与 840，行 y = 50 与 550（格间距 ≥ 80）；
   - 六格 2×3：格 480×280，列 x = 60 / 560 / 1060，行 y = 50 / 360 / 670；
   - 条横排（条漫）：一行 3~4 格，格 380~480 宽、300~360 高。
2. 每格上方外侧可加小号格号（可选）；不画跨页大格子。

## 五、逐格绘制（一格画完再画下一格）

1. **场景**：有场景模板就 stamp_template(name, x, y, scale) 盖进格里（scale ≈ 格宽/模板宽，且 ≤ 1.2），没有就先画简易地面线 + 1~2 个标志物。
2. **角色**：stamp_template(name=角色名, x, y, scale≈1, flip_x=朝向)——对话双方**相对而立**（左边的角色 flip_x=false 面朝右，右边的 flip_x=true 面朝左）；同一角色在同一格里只出现一次。
3. **大小一致**：同一角色在相邻格中的高度差 ≤ 25%，除非剧情需要远近景（远景 scale 0.6~0.7，特写 scale 1.5 且只盖章头部区——即 y 上移、加大 scale）。
4. **台词**：draw_speech_bubble(x, y, w, h, text, tail=方向)——气泡放在格子内**上方空白处**，尾巴指向说话者嘴部方向（说话者在气泡左下用 down_left，右下用 down_right）。旁白用 draw_rectangle（浅黄 0xFFF9DB solid 底）+ draw_text 放格子顶部。
5. **表情/动作**：在盖出来的角色上**叠加**小元素表达：眉毛/嘴（两条短线）、汗滴（小蓝椭圆）、怒符（红色十字折线）、速度线（2~3 条短斜线）、爱意（小桃心 polygon）。禁止为改表情把角色删掉重画。
6. **冲突检查**：气泡之间、气泡与角色之间不重叠；气泡必须完全在自己那格的边框内（四周留 ≥ 12）。

## 六、完成后自检

全部画完后调用一次 list_elements（画的过程中不要反复调）核对：
1. 每个角色在各格中的配色是否与模板一致（盖章保证一致，若手滑重画了要删掉改成盖章）；
2. 元素是否出格、气泡是否压住角色、文字是否溢出；
3. 阅读顺序是否自然。发现问题的格子用 update_element 修正后再结束。

## 七、禁止行为

- 禁止跳过模板直接在多格里反复手画同一个角色（那是一致性事故）。
- 禁止给同一角色在不同格里换衣服颜色、换发型。
- 禁止把气泡画出格框、盖住关键角色。
- 禁止一格里塞超过 3 个角色或 3 条对话。
- 禁止没有剧本就直接开画（先在思考里把分格表列全）。
