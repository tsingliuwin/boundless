## 第 1 轮：E2E 首跑 —— 五个坑，两个真 bug

| # | 症状 | 根因 | 修复 |
|---|---|---|---|
| 1 | 校准只找到 1 个图标簇 | **菜单栏底部分隔线**是全宽 1-2px 暗线，把行带从菜单栏一直连到工具栏，所有列被判为暗列 | 行带按连续段分组，取「图标簇最多」的段（scenarios.py） |
| 2 | 校准把聊天窗口当应用 | 前台漂移：用户操作后 boundless 不在前台，拍到 ZCode 暗色 UI | `find_toolbar_buttons` 前强制 `kit.activate()` |
| 3 | CGEvent 脚本 **SIGSEGV**；点击落点随机 | **arm64 ABI 错误**：CGPoint 是按值传参（浮点寄存器），骨架声明成 `c_double*2` 数组按指针传 | 改用 `ctypes.Structure`（kit.py）。⚠️ 骨架提交时未实跑，此 bug 会静默吞掉所有鼠标事件 |
| 4 | 截图整屏全黑、事件不达 | **显示器睡眠**（displaysleep=2min，合成事件不重置空闲计时；右下热角设了锁屏/睡眠动作；用户手动锁屏断言也拦不住） | kit import 时 `caffeinate -u` 唤醒 + `-d` 持有断言；`shot()` 黑帧自愈重拍 ×3 |
| 5 | 拖拽有时画不出 | 坑 3/4 的复合症状 | 同上 |

**真 bug #1（产品）：macOS 上 Cmd+Z 无绑定。** E2E-007「撤销还原像素」永远不过；
应用侧调试日志证明事件已到达。查 `main.rs` 键表：编辑命令族只绑了 Windows 风格
`ctrl-*`（undo/redo/save/open/插入图片/层序/缩放/AI 面板/设置 全部中招）。
按既有 cmd-q+ctrl-q 并存模式补齐全部 Cmd 变体（cmd 修饰键在 Windows 不存在，
绑定天然不触发，零风险）。修复后 E2E-007 PASS。
（注：Ctrl+Z 在 macOS 上一直可用，故日常未暴露。）

**真 bug #2（harness 阻断级）：坑 3 的 ABI 错误。** 按计划里「未实跑不合并」的
原则这本不该发生；教训已写入 e2e/README「踩坑实录」。

## 遗留与风险

1. 用户手动锁屏/按电源键仍会中断 E2E（断言拦不住用户操作）——黑帧自愈
   可重试 3 次，通常够用；遇到连续失败先看 `/tmp/e2e-artifacts/*` 是否黑帧。
2. 右下热角设了锁屏/睡眠动作（wvous-br-corner=14）：合成事件坐标有 bug 时
   可能误触，harness 已把光标停靠屏幕中心规避。
3. E2E-003~012（渐变五切换/图片/文本/演示/保存恢复等）待按 §4.4 逐个补齐，
   机制已全部验证可复用。
4. 应用侧 e2e_debug 日志当前仅覆盖鼠标事件，后续补 key/undo 事件会更省事。
